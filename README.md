# Burari

Public pages for Burari, served by GitHub Pages from `docs/`:

- [Privacy Policy](https://yabutaka.github.io/Burari/privacy-policy.html) (`docs/privacy-policy.html`)
- [Terms of Service](https://yabutaka.github.io/Burari/terms.html) (`docs/terms.html`)

Burari helps you build a personal map of places to explore. Share an Instagram reel or
post about a place with Burari on Instagram, and it finds the place and pins it to your
map in the Burari iOS and Android app.

The HTML pages are the only copy of the policy and terms -- edit them there, and update
the "Last updated" date.
